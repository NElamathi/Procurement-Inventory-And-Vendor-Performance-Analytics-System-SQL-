# Procurement, Inventory and Vendor Performance Analytics System

## Project Description

This project is a SQL-based database system for managing and analyzing procurement, inventory, warehouse, product, vendor, category, and delivery data.

## Main Tables

- Products
- Vendors
- Categories
- Inventory
- Warehouses
- Deliveries

## SQL Topics Implemented

- SELECT and WHERE
- AND, OR, BETWEEN, IN
- LIKE and IS NULL
- ORDER BY
- LIMIT and OFFSET
- Aggregate Functions
- GROUP BY and HAVING
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Subqueries
- CASE Statements
- Views
- Stored Functions
- Triggers
- Indexes
- Transactions
- UNION
- Window Functions
  - RANK()
  - DENSE_RANK()
  - ROW_NUMBER()

## Purpose

The purpose of this project is to demonstrate SQL database management and analytical queries using a procurement and inventory management system.
